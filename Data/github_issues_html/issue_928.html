The correct setting if you are using the flake is `programs.auto-cpufreq`. This is different from the setting declared in nixpkgs which is `services.auto-cpufreq`. The [README](lhttps://github.com/AdnanHodzic/auto-cpufreq?tab=readme-ov-file#nixos) contains different instructions for installing via the flake or from the nixpkgs repo, so the current version has the correct instructions. If you are installing via the flake and having issues with `programs.auto-cpufreq` not being recognized, its most likely that something is wrong with your nix config.
