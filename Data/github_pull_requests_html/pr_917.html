Add bluetooth controls to the GUI, and fix bluetooth conf updates for commented lines

Pull Request #917

Description

This adds a new radio dialog for in the GUI for setting the bluetooth modes similar to the CLI. I noticed when testing it was not working, the previous impelementation was using a find and replace string to update the main.conf file for bluetooth configurations, which for me on arch linux was just updating a commented line in the configuration file which is the how the file is setup by default. ```bash # AutoEnable defines option to enable all controllers when they are found. # This includes adapters present on start as well as adapters that are plugged # in later on. Defaults to 'true'. #AutoEnable=false ``` I added more robust parsing to determine current bluetooth settings and updated the replacement mechanism to deal with commented lines in addition to proper location placement under the [Policy] section in the bluetooth config file.
