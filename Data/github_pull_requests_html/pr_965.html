## Summary Fixes the `power-profiles-daemon` handling [issue](https://github.com/AdnanHodzic/auto-cpufreq/pull/962#issuecomment-5365358892) pointed out. The native install path could incorrectly infer that auto-cpufreq was installed via Snap and recommend re-enabling `power-profiles-daemon`. This change removes that incorrect Snap inference from the native path and uses the actual `power-profiles-daemon` service state instead.
